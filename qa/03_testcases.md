## 결함 후보 승격 검토 대상 (이번 4단계에서 신규 식별, 아직 결함 확정 아님 — 실행 후 판정)

1. **검색어 특수문자 필터 인젝션 위험**(TC-EQ-042/TC-ERR-12) — `prayer_provider.dart:95` `.or()` 문자열에 사용자 입력 미이스케이프. RLS로 데이터 유출은 없으나 기능 오류(400/크래시) 가능성.
2. **저장 버튼 연타 가드 미확인**(TC-ERR-01) — `_canSave`가 `_isSaving`을 반영하는지 코드상 명확치 않음, 중복 insert 가능성.
3. **수정 대상이 이미 삭제된 경우 update 0행을 성공으로 오인**(TC-ST-025/TC-ERR-14) — `.update().eq('id',...)`에 결과 행 수 체크 없음.
4. **SPEC.md 8-2 표가 draft 자동저장(B2) 구현 이전 서술 그대로 남아 실제 코드와 불일치**(TC-ST-022) — 결함이 아니라 문서 정합성 이슈.

이 4건은 실행 우선순위가 높은 것부터(①③) 다음 세션에 **직접 실행**해서 결함 확정 여부를 판정할 것을 권장.
