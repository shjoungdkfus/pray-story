## 신규 결함 — 전부 실기기 재현·수정·재검증 완료 (2026-07-26)

### PS-UI-01 — ✅ 수정 완료

갤럭시 S23에서 `adb shell settings put system font_scale 2.0`으로 재현: 기록탭 달력의 날짜 그리드가 통째로 화면 밖으로 밀려 1일 이후 숫자가 전부 안 보임, 지난기록 제목/본문도 심하게 잘림. **1.3배율에서도 이미 달력 마지막 줄이 잘려** 낮은 배율부터 깨지는 것을 확인. `lib/main.dart`의 `MaterialApp.builder`에서 `MediaQuery`의 `textScaler`를 `clamp(maxScaleFactor: 1.0)`로 확대만 제한(축소는 그대로 허용 — 기존 기기 배율 0.8에서 문제없이 잘 쓰이고 있었으므로)하도록 수정. 재검증: 200% 배율에서도 달력 1~31일 전부 정상 표시, 홈 화면도 정상 크기 확인. 상세는 `qa/04_defects.md` PS-UI-01 참고.

### PS-CRUD-04 — ✅ 수정 완료

같은 기기에서 테스트계정으로 로그인 후 기록탭 검색에서 "gratitude" 검색해 매칭 확인 → 오프라인 전환 → 검색어를 "gratitude!"로 변경(지우지 않고 이어쓰기)했더니 이전 매칭 결과가 새 검색어의 결과인 것처럼 그대로 남아있고 아무 에러 표시도 없음을 재현. `history_search_overlay.dart`를 `results.when(loading/data/error)`으로 명시적 3분기하고 에러 시 `searchError`(신규 ARB 키) 안내 문구를 노출하도록 수정. `ref.listen`도 빈 리스트를 포함해 항상 `_lastResults`를 갱신하도록 바꿔 "진짜 빈 결과"와 "에러로 인한 stale 표시"를 분리. 재검증: 오프라인 시 에러 문구 정상 노출, 온라인 복귀 후 재검색도 정상 동작 확인. 상세는 `qa/04_defects.md` PS-CRUD-04 참고.
